## Rules that bind the order

- Nothing faulted is compared with its clean arm on true glucose before M8 (D13). Before the tag, harness tests may run faulted inputs on seeds outside the main grid and check controller actions, CGM streams and meals only.
- After M8 every change is a dated amendment in DECISIONS.md, made before anything it affects is computed (AGENTS.md rule 11). A pre-specified rule applied after the tag is logged the same way and changes no rule.
- Patients are never dropped; CIs run across patients, not seeds (AGENTS.md rule 8).
