## 2. oref0 bridge (node/bridge.js)

- One long-lived, stateless JSON-lines worker; Python sends the whole state each call. Ops: `step`
  (glucose-get-last, lib/iob, lib/meal, determine_basal), `profile` (lib/profile, wired as
  bin/oref0-get-profile.js:217-244), the single stages `glucose_status`, `iob`, `meal`,
  `determine_basal`, plus `ping` and `exit`.
- Each stage is wired as its CLI (file:line in the code) and gets its own fresh copy of the inputs,
  because oref0 mutates them (lib/iob/history.js:269-270 adds `timestamp`, glucose-get-last.js:48
  averages into the newest entry, cob.js:143-144 rewrites `clock` and `current_basal`). The IOB and
  meal results pass through a JSON round trip, as they do through files in the CLI. The CLI-only
  checks of bin/oref0-meal.js are kept (carb ratio < 3, lines 88-92; fewer than 36 readings, lines
  131-135).
- SMB: the library is called directly, so microBolusAllowed is honoured (the CLI turns it off without
  an `autotune` directory, bin/oref0-determine-basal.js:105-114).
- stderr: console.error/log/warn/info and process.stderr.write are dropped (returned in `log` with
  `debug: true`); rT.reason is kept. The bridge writes replies through a saved stdout handle.
- Runs with TZ=UTC (the Python client sets it).

### 2.1 Wall-clock reads reachable from the bridge

| Read | Reached? | Neutralised by |
|---|---|---|
| determine-basal.js:133,145 `new Date()` | always executed, then overwritten | `currentTime` = simulated clock |
| lib/iob/index.js:39, history.js:175 `tz(inputs.clock)` | yes | `inputs.clock` = simulated clock |
| lib/meal/index.js:19 `tz(inputs.clock)` | yes | `inputs.clock` = simulated clock |
| cob.js:26 -> history.js:175 with `inputs.clock` undefined (lib/meal/total.js:22-31 builds the IOB inputs without a clock) | yes, first cob.js call of every lib/meal run | `moment.now` set to the simulated clock per request (moment's documented clock hook; moment and moment-timezone are one instance) |
| lib/iob/calculate.js:18 `new Date()` | no: total.js:72 always passes `time` | - |
| lib/profile/basal.js:11 | no: history.js:522 and cob.js:144 pass a date | - |
| lib/profile/isf.js:10 | no: cob.js:126 passes `bgTime` | - |
| lib/profile/{targets,carbs}.js, lib/medtronic-clock.js, isf/basal lookups in lib/profile/index.js | only in the `profile` op, once per patient | single-entry schedules: the result cannot depend on the time |
| history.js:272 `tz(current.timestamp)` with no timestamp | no: every ledger record has `created_at` | - |

The cob.js read is not cosmetic: with the wall clock before the simulated time, every pump record
counts as "in the future" (history.js:276) and the deviations lose all insulin; after it, the
temp-cancel event (history.js:370-372) lands in the wrong place. Pinning moment's clock gives
exactly what a live rig sees (wall clock = data clock).

### 2.2 Tests (all pass)

- tests/test_bridge_parity.py: node/parity_fixtures.js records all 42 determine_basal calls of
  oref0's tests/determine-basal.test.js (by wrapping the function in its own process's require
  cache) and adds 10 derived fixtures for branches that file never reaches (SMB microbolus, SMB off,
  maxDelta SMB block, stale data x3, flat CGM, fakecgm bypass, noise 3, low suspend with a real IOB
  array). All 52 rT identical through the bridge; currentTime pinned on both sides.
- tests/test_bridge_cli.py: bin/oref0-calculate-iob.js, oref0-meal.js and oref0-determine-basal.js
  with Date pinned by node/preload_clock.js, on 5 states x 2 ISF rules: full IOB array, meal data,
  glucose status and rT identical (SMB off).
- tests/test_bridge_clock.py: the same profile and step requests in two bridges whose wall clock is
  moved to 2019 and to 2034: identical replies. Negative control: with moment left on the wall
  clock (test-only `wallclock: true`), lib/meal's output differs between the two.
- oref0's own mocha suite (determine-basal, iob, get-last-glucose, basal): 84 passing.

## 3. Deviations from TECHNICAL_DESIGN.md

1. §2: oref0 is not vendored under `vendor/oref0/`; it is installed from npm into node/node_modules
   from the committed node/package-lock.json (`npm ci --ignore-scripts`). The lockfile also holds
   oref0's full declared dependency tree (request, share2nightscout-bridge, ...), but the bridge
   requires only lib/ modules, which need lodash, moment and moment-timezone.
2. §1.1/§2: one more wall-clock read than the design lists (cob.js:26 via lib/meal/total.js), handled
   as in §2.1 above.
3. §6: the profile is generated by oref0's own lib/profile from pump settings, so the scheduled basal
   oref0 sees is rounded to 0.001 U/h (lib/profile/index.js current_basal via basal.js:29), while the
   pump delivers paper 1's exact basal. Difference at most 0.0005 U/h.
