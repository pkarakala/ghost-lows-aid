# Reference layer

The exact protocol, for reviewers and agents. Each fact has one source file; the human layer ([README](../../README.md), [SUMMARY](../SUMMARY.md)) links here.

- [RESEARCH.md](RESEARCH.md): definitions, questions, the hypotheses H1-H2 and comparison C1, what is new, scope, limitations, credibility.
- [SIMULATION.md](SIMULATION.md): simulator, cohort, controllers and settings, the oref0 bridge, the person, faults, run design, arms, seeds, grid, storage.
- [BENCHMARK.md](BENCHMARK.md): outcomes, estimands, statistics and decision rules, the alarm layer, outputs, sensitivity analyses, reading rules.
- [DECISIONS.md](DECISIONS.md): every design decision with alternatives, reasons and evidence; items open for the project lead; amendments after `protocol-v1`.
- [../CLINICAL_REVIEW.md](../CLINICAL_REVIEW.md): the clinical judgements the protocol depends on (CR items).
- [../CITATIONS.md](../CITATIONS.md) and [../references.bib](../references.bib): every source and its status.
- [../development/](../development/): the harness record (SPIKE), analysis notes and the roadmap.
